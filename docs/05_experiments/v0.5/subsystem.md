# 阶段6：官方SoC子系统连接与AI内存窗口

FPGA提交8bbc931e：从实际96MHz Sapphire公共声明和官方TinyML接口生成子系统外层，显式连接全部78个Sapphire端口与35个TinyML AXI端口。自定义指令及中断连接沿用官方EVSoC，APB1连接已验证的手势结果/Overlay端点。CPU内存响应ID和错误响应保留，等待共享内存通路接入。

AI窗口逻辑[0x00001000,0x04001000)对应物理[0x04000000,0x08000000)。新cnn_axi_window检查整个128位INCR突发的范围、4KiB边界、对齐及溢出，非法访问在本地返回DECERR，不触碰原视频低48MiB。首/末地址、非法读写、数据拍数、ID/错误回传和回压仿真通过，零错误/警告。

外层自有RTL语法编译通过；尝试编译完整官方IP时，本机ModelSim10.6e对Efinix加密区报错，exit2。没有替换成虚假功能模型，也没有完整SoC仿真通过的结论。后续需要通过Efinity官方综合/实现验证。报告与哈希见 [subsystem_report.json](subsystem_report.json)。

当前尚未接入example_top和物理DDR。窗口是隔离/转换模块，不是仲裁或完整缓冲：需要完整写突发缓存、读响应容量保证、共享仲裁及复位排空规则，避免AI停顿拖停视频。接入之后仍需RAW8预处理、输入缓冲和软件推理主循环，最后完成综合布局布线与板上验证。阶段6仍未完成。
